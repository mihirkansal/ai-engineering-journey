# Learning artifacts

Small programs I wrote for lesson tasks. Each folder is named `<phase>-<lesson>`. Run any file with `python3 file.py` to see its demo output.

| Folder | File | What it does |
|---|---|---|
| 02-12 | grid_size.py | Counts how many combinations a grid search would try |
| 02-13 | scale_train_test.py | Scales test data using only the training data's statistics (a leakage fix) |
| 02-14 | smoothed_prob.py | Laplace-smoothed word probability for Naive Bayes |
| 02-15 | make_lags.py | Builds lag features without leaking the target (a bug fix) |
| 02-16 | z_outliers.py | Flags values whose z-score passes a threshold |
| 02-17 | precision_recall.py | Precision and recall from true positives, false positives and false negatives |
| 02-18 | low_variance.py | Names the columns whose variance is below a threshold |
| 02-19 | in_flight.py | Little's law: requests being handled at the same moment |
