# AI Engineering Journey

I am learning to become an AI engineer in public. I am working through the free, open-source course [AI Engineering from Scratch](https://github.com/rohitg00/ai-engineering-from-scratch) (MIT licence, by Rohit Ghumare and contributors), all 20 phases in order.

I study with an AI tutor (Claude Code) that teaches each lesson step by step. Every function in this repo is code I typed myself in answer to a lesson task; the tutor ran it and told me when it was wrong.

## What is here

| File or folder | What it holds |
|---|---|
| [PROGRESS.md](PROGRESS.md) | One row per lesson: real date, quiz score and what I learned |
| [learning-artifacts/](learning-artifacts/) | The code I wrote for lesson tasks, one folder per lesson |

## Where I am

Phase 2 (ML Fundamentals): lessons 1 to 18 finished, lesson 19 in progress. Phases 0 and 1 (setup, math) are done.

## Honest notes

- Scores are my real first-attempt quiz scores, including the low ones.
- When I got a task wrong, the saved file is my final working version, not my first attempt.
- Nothing here is back-dated: the dates in the log and in the git history are the days the work was done.
